FAQ

Questions, answered.

Token safety, permanent deletions, and what the tool can touch — before you connect an account.

How do I bulk delete Vercel projects?

Open the manager, paste a Vercel API token, select the projects you want to remove, and confirm. Every selected project is deleted in a single pass instead of one at a time from the Vercel dashboard.

Is Vercel Bulk Manager free?

Yes. It is free to use, with no signup, subscription, or installation. All you need is a Vercel API token.

Is it safe to paste my Vercel API token?

The token is stored in your browser's localStorage, and requests go directly from your browser to the Vercel API — there is no server in between. The source code is public, so you can verify that before granting access. Use the narrowest token you can, and revoke it when you are done.

Can I undo a deleted project or deployment?

No. Deletions are permanent. Check the selection carefully — especially when using Select all — before you confirm.

Does it work with team accounts and every Vercel plan?

Yes. It works with all Vercel plan types, including personal and team accounts, as long as your API token can access the projects you want to manage.

What Vercel API token do I need?

Create a token in your Vercel account settings, choose the scope you need, and set the shortest expiry that works for you. A token with access to the projects you plan to delete is enough.

Is Vercel Bulk Manager an official Vercel product?

No. It is an independent third-party tool built by Hyperdyn. It is not affiliated with, endorsed by, or supported by Vercel.
