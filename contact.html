Frequently asked questions

Is my Vercel API token safe?

The tool stores your token locally in your browser's localStorage. According to the developer it is never transmitted to external servers, and API calls go straight from your browser to Vercel. That claim is worth verifying in the source code before you grant access.

Can I recover deleted projects?

No. Deletions are permanent and cannot be undone. Always double-check your selections before confirming any delete operation.

Is Vercel Bulk Manager free to use?

Yes. It is free to use with no hidden costs.

How do I get a Vercel API token?

Create one at vercel.com/account/tokens and paste it into the app. Use the minimum permissions you need, and revoke it when you're done.

Where can I submit a feature request?

Open an issue on the GitHub repository with the “enhancement” label.
